# Hydro-Lab S2.11 — Incremento 03 / G0.1

## Instrumentación experimental descriptiva (primera etapa)

**Base obligatoria:** S2.11 incremento 02, 102 pruebas superadas. Este paquete es **diferencial**: agrega un módulo y pruebas; no reemplaza ningún archivo previo.

### Alcance entregado

1. Lectura y validación del CSV de evaluación por escenario y política.
2. Resumen de retorno medio/mediano, dispersión, terminaciones anticipadas, déficit, energía e intervenciones.
3. Comparaciones **pareadas por semilla**: diferencia de retorno PPO − referencia, victorias, empates y derrotas. Una diferencia positiva favorece PPO.
4. Exportación de `resumen_validation.csv`, `pareadas_validation.csv`, `informe.json` y `curva_entrenamiento.csv` (si existe `rollouts.json`).
5. Pruebas automatizadas para los cálculos, el manejo de duplicados y datos no finitos.

### Ejecución

Desde la raíz del proyecto:

```bash
python -m pytest -q
python -m hydro_lab.s211_instrument --checkpoint resultados/s211_ppo_piloto --split validation
```

Los informes se guardan en `resultados/s211_ppo_piloto/instrumentacion/`.

**Importante:** `resultados/s211_ppo_piloto` debe existir **en este proyecto**. Si el entrenamiento piloto quedó en la copia externa del incremento 02, se debe utilizar la ruta absoluta de ese checkpoint con `--checkpoint`, sin copiarlo ni reentrenar.

### Límites y siguientes etapas

El `rollouts.json` del incremento 02 almacena la recompensa del último episodio observado por rollout, aunque su clave se llame `mean_episode_reward`; **no es una media móvil**. La curva exportada no permite aún evaluar convergencia con rigor. Este incremento no agrega evaluación periódica durante entrenamiento, múltiples semillas de entrenamiento ni intervalos de confianza: serán la **etapa 2 de instrumentación**, después de validar esta etapa descriptiva. No interpretar el piloto de 4096 pasos como evidencia de aprendizaje suficiente.

No se modifica el simulador S2.10, la recompensa UM, las particiones de semillas ni el modelo PPO. No se consultan variables privilegiadas durante la inferencia.
