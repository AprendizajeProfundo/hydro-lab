# Hydro-Lab G2 — S2.8: Integración de observación activa y control hidráulico

**Estado:** versión experimental para validación en el entorno Mac del curso. Preserva S2.7 en una carpeta distinta.

## Hipótesis de trabajo

Las inspecciones aportan observaciones ruidosas que actualizan la creencia sobre salud de las bombas. Un controlador que usa esa creencia puede redistribuir las consignas entre bombas. El efecto neto debe evaluarse, no presumirse positivo.

## Contrato de información

El controlador recibe únicamente el vector observado de 15 componentes, incluidos los índices 12–14 (salud estimada). Nunca recibe la salud física verdadera ni `evaluation_truth`. La inspección ocurre **después** del paso hidráulico; su información se utiliza **desde el paso siguiente**, sin anticipación temporal.

## Controlador `health_aware`

Primero calcula el comando normalizado del controlador `demand_feedback`: `a_base`. Luego utiliza las tres estimaciones observadas `h`:

`a = clip(a_base + 0.65 * (clip(h,0.65,1) - mean(clip(h,0.65,1))), -1, 1)`.

La corrección se centra para no modificar, antes del recorte, el promedio de los comandos. Esto es una **heurística de asignación basada en salud estimada**, no un controlador óptimo, un modelo de fiabilidad ni una garantía de seguridad. La protección del entorno sigue operando.

## Diseño experimental pareado

Cuatro brazos, para cada semilla:

1. `demand_feedback` + `off` (referencia)
2. `health_aware` + `off` (efecto de política)
3. `demand_feedback` + `uncertainty` (costo de observación sin uso explícito)
4. `health_aware` + `uncertainty` (integración completa)

El contraste principal es (4) menos (2) en recompensa neta, que ya descuenta el costo del robot. También se registran energía, demanda no atendida, intervenciones, terminaciones e inspecciones. Se emparejan semillas; al divergir las trayectorias, la evolución aleatoria interna puede dejar de coincidir perfectamente. No se presentan los resultados descriptivos como inferencia causal definitiva.

## Uso en Mac

Desde el directorio `hydro-lab-g2` de S2.8:

```bash
conda activate hydro-lab
python -m pip install -e ".[dev,ui]"
python -m pytest -v
python -m streamlit run dashboard/app.py
```

En el panel, seleccionar **Control sensible a salud** y **Priorizar incertidumbre**, crear episodio y avanzar. En **Comparar controladores**, ejecutar **Experimento factorial de observación activa** para contrastar los cuatro brazos.
